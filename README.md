An end-to-end Machine Learning credit decisioning engine built to assess "thin-file" borrowers and unbanked applicants. By leveraging non-traditional data—including cash-flow dynamics, utility payment consistency, and transactional metadata—**AltScore AI** quantifies default probability, optimizes financial thresholds, and delivers regulatory-compliant adverse action reasons.

---

## 🚀 Key Features

* **Alt-Data Feature Engineering:** Extracting cash flow stability, utility reliability, and spending behavior metrics.
* **Dual-Model Decision Engine:** Traditional **WoE-Logistic Scorecard** (for regulatory compliance) vs. **XGBoost Classifier** (high-accuracy challenger).
* **Explainable AI (XAI):** Integrated **SHAP** pipeline providing top drivers for credit approval or denial.
* **Profitability Optimization:** Business thresholding to maximize expected net revenue based on default loss trade-offs.
